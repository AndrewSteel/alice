Alice — ein privater KI-Sprachassistent

// lokal gehostet, per Sprache bedienbar, nur für den eigenen Haushalt

Privates Projekt, im Aufbau

Alice ist ein selbst entwickelter, lokal auf eigener Hardware betriebener KI-Assistent für den Hausgebrauch. Alice versteht gesprochene Anfragen, steuert Smart-Home-Geräte und beantwortet Fragen — alle Berechnungen laufen auf einem eigenen Server, nicht in der Cloud eines Drittanbieters.

Auf Wunsch kann Alice mit dem eigenen Google-Konto verbunden werden, um Kalendereinträge, Aufgaben oder Kontakte im Gespräch abzurufen und zu verwalten. Diese Verbindung ist freiwillig, wird ausschließlich vom jeweiligen Nutzer selbst eingerichtet und kann jederzeit wieder getrennt werden.

Details dazu, welche Daten dabei verarbeitet werden, stehen in der Datenschutzerklärung, die hier zu finden ist.
